Square icon button with an optional caption label, used for the quiz side-rail controls (Home / Hint / Sound / Retry / Next).

```jsx
<IconButton icon={<Home size={22}/>} label="Home" variant="neutral" onClick={goHome} />
<IconButton icon={<Volume2 size={22}/>} label="Read it" variant="primary" />
```

Variants: `primary`, `accent`, `neutral` (default), `success`.
